# Hearth roadmap

Future work is grouped into planned releases. Release names and contents are plans;
the matching Git tag is created only when a release ships.

## v0.3.0

**Status:** Planning

**Goal:** To be defined with Ethan.

### Features

- [ ] Define the release goal and select features from the unscheduled scope.

## Unscheduled product scope

These capabilities are already part of Hearth's documented product vocabulary but
have not been assigned to a release:

- Calendar and Events
- Meal Plan, Meals, Recipes, and Ingredients
- Add Recipe Ingredients to the Grocery List
- Notes
- Messages
- Expenses using manual or mock data first
- Payment Source integration through a third-party aggregator after the manual
  Expense flow is established

## Unscheduled platform work

- CI that runs automated checks on every push
- Household timezone setting
- Multi-Household support and an active-Household switcher
